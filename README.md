|:--------------------:|:---------------------------------------------------------------:|:--------------------------------------------------------------------:|
|    Forge (1.8.9)     |                      Bundled (via tweaker)                      |    Bundled (via tweaker, can be overriden with separate download)    |
| Fabric (1.8.9/26.1+) |                  Required (separate download)                   |                     Required (separate download)                     |
